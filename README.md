# ASAM OpenSCENARIO XML examples subset

This directory contains a **selected subset** of official example scenario files (`.xosc` and `.xodr`) collected from official [ASAM OpenSCENARIO XML](https://www.asam.net/standards/detail/openscenario-xml) releases.

For v1.4.0, the example package can be found [online](https://publications.pages.asam.net/standards/ASAM_OpenSCENARIO/ASAM_OpenSCENARIO_XML/v1.4.0/index.html) under top right `Deliverables` menu.

## Purpose
These specific examples are included to provide lightweight test assets and compatibility checks for esmini without importing the entire release package.
